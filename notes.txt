Title 2: PARAMETER (url's parameter)
1..PATH PARAMETER:
    - Specific resource identify panna,
    - URL:	/students/101,
    - Syntax:	{student_id},
    - FastAPI:	"/students/{student_id}"
2.QUERY PARAMETER:
- Data filter/search panna,
- URL: /students?department=CSE,
- Syntax:	?department=CSE,
- FastAPI:	"/students"
3.REQUEST BODY: used to Send data in structured manner to server/DB/backend
4.PYDANTIC MODEL: library to create request BODY
//uses
 - validation
 - serialization(example : when dataset in JSON format but i want to change before send to backend  )
 - documetation
